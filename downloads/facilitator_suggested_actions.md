# 帶領員建議行動指引

> 本文件為《帶領員工作手冊》各步驟補充引導方向，重點在於帶領員應引導的概念與方向，而非固定說話內容。

---

## 活動一：解決實施障礙

### 活動定向

教師將日常推行自由遊戲時面對的困難寫成紙條，交換給另一組分析並提出解決方案，最後全場分享。交換這一步是刻意設計的——從旁觀者角度看別人的困難，往往比困在自己的問題裏更容易找到出路。帶領員的任務是確保討論落地：參加者離場時應帶走至少一個即時可行的改變方向。

### 活動目標

- 協助教師整合所學，識別並解決在幼稚園推行自由遊戲時持續面對的困難
- 運用 CPS（兒童遊戲性量表）的五個維度分析障礙
- 為最困擾的挑戰制訂具體可行的解決方案
- 與全場分享小組洞見

| :----------: | :--------: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   **介紹**   | **3分鐘**  | **帶領員行動：**`<br>`1. 介紹活動目標`<br>`2. 介紹收集困難的方式（紙條）`<br>`3. 說明流程（識別→傳遞→分析→分享）`<br><br>`**【帶領指南】**`<br>`• 說清楚傳遞規則：紙條放入信封後，**跳過緊鄰一組，傳給順時針方向第��組**——讓收到紙條的組感覺更像陌生人視角，距離感有助減少情緒包袱`<br>`• 強調「交換」機制的價值：從旁觀者角度分析問題，比困在自己的困難中更容易找出路`<br>`• 語氣宜輕鬆，讓參加者明白今日不是考試，而是互相學習                                                                                                                                                                                                                                                                                                  | **參加者行動：**`<br>`了解活動目的及流程                                                                                                                                            |

| **整合分析** | **15分鐘** | **帶領員行動：**`<br>`1. 各組從收到的紙條中**抽取5張**進行分析（不是全部）`<br>`2. 提醒聚焦於可控範圍內的解決方案`<br><br>`**【帶領指南】**`<br>`• **說明抽取邏輯**：5張不是隨機抽，而是先快速瀏覽全部紙條，再挑選「最有共鳴」或「最想回應」的5張——這本身已是一次優先次序的練習`<br>`• **引導優先次序**：協助小組以「影響力 × 可行性」思考，從5張中再揀最值得深入分析的一個，而非嘗試解決全部`<br>`• **引導落地**：解決方案要具體到「明天返校即可試行」；若方案過於理想化（如「要求增加空間」），引導小組思考在現有條件下的第一步`<br>`• **引導 CPS 連結**：幫助小組思考方案如��具體改善小朋友某個 CPS 維度的體驗，而非只停留於執行層面`<br>`• **可用材料**：CPS 提示表協助小組將挑戰對應到具體維度；困難排行榜協助視覺化優先次序 | **參加者行動：**`<br>`1. 從收到的紙條中抽出5張`<br>`2. 以「影響×可行性」排列優先次序`<br>`3. 就最優先挑戰提出一個解決方案，連結 CPS 維度`<br><br>`*所需材料：困難排行榜、CPS提示表* |
| **全場分享** | **10分鐘** | **帶領員行動：**`<br>`邀請五個小組進行站立分享（每組1分鐘）`<br><br>`**【帶領指南】**`<br>`帶領員在此步驟是「**主持人兼串連者**」，而非只是傳聲筒：`<br>`• **串連各組**：主動點出不同組之間的共同困難或相近方向，讓分享成為集體學習`<br>`• **突出可控的改變**：引導全場看到，教師每日的小決定（何時介入、何時退後）本身就是推動自由遊戲的核心行動`<br>`�� **重新定位教師角色**：帶出「不介入」是一種專業判斷，而非放任`<br>`• **保持正向**：若討論出現無力感，溫和地引導至「我能做的第一步」`<br>`• **時間管理**：若某組分享過長，可說：「這個方向很值得，我們先記下來，讓其他組也有機會分享。」                                                                                                                                  | **參加者行動：**`<br>`各組代表向全場分享主要結論                                                                                                                                    |

## 活動二：「我們的玩樂社區」資源地圖

### 活動定向

各組以地區為單位，在共同地圖上標記並評估社區遊玩空間。目的很實際：讓教師更熟悉自己社區的資源，從而在日常對話中更有信心向家長推薦適合帶孩子去的地方。帶領員不需要把它變成大道理，重點是幫助各組發現身邊被忽略的空間，並想清楚怎樣向家長說得出口。

### 活動目標

- 運用 CPS 遊戲性維度評估社區空間
- 共同創建社區資源數碼地圖（透過 Padlet）
- 發掘能補充城市遊戲限制的機會
- 為家長制訂實用的帶孩出外遊玩建議

### 流程及帶領指南

| :----------: | :--------: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
|   **介紹**   | **2分鐘**  | **帶領員行動：**`<br>`說明活動目標：共同製作地圖`<br>`介紹 Padlet 及流程`<br><br>`**【帶領指南】**`<br>`• 確認各組已進入正確地區的 Padlet 頻道（常見技術問題，需實地核查；若有人未能登入，先讓他們觀察旁邊同組的螢幕）`<br>`• 定調氛圍：今日不是���旅遊攻略，而是用遊戲性的眼光重新發現社區裏被忽略的空間`<br>`• **傳遞概念**：教師對社區的了解本身就是一種專業資產——這個活動是把腦中散落的知識整理出來，變成可以跟家長分享的素材                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | **參加者行動：**`<br>`掃描二維碼進入 Padlet`<br>`確認已在正確的地區組                                                        |

| **全場分享** | **15分鐘** | **帶領員行動：**`<br>`每個地區各選一組進行站立分享（共5組），每組約2分鐘`<br><br>`**【帶領指南】**`<br>`帶領員在此步驟的核心任務是**讓「wow moment」浮現**，而非整理知識框架：`<br>`• **聚焦「wow moment」**：引導各組分享的不是地圖整體，而是討論過程中那個讓人「原來如此」的瞬間——在一個熟悉的地方突然看到新的遊戲可能，或發現某個冷門地點其實非常適合自由探索`<br>`• **鼓勵具體畫面**：若某組提到一個地點，可以問：「你們在說這個地方時，有沒有一個孩子玩耍的畫面浮現腦海？」幫助分享變得有溫度`<br>`• **串連各地區**：點出不同地區的相似發現或有趣對比，例如：「兩個不同地區都提到水這個元素——看來水對孩子的吸引力是跨地區的。」讓地圖成為集體發現，而非各組孤立的結論`<br>`• **強調教師作為橋樑**：今日教師發現了什麼，就是他們明天可以告訴家長的東西——不需要等培訓，走出去看看就是行動`<br>`• **地圖的延續價值**：提醒參加者地圖活動後將整理成可分享的社區資��，鼓勵持續補充                                                                                        | **參加者行動：**`<br>`各組代表向全場分享一個印象深刻的發現或討論中的「wow moment」                                           |

## 帶領員注意事項

### 活動一

**整合分析**階段最容易出現兩個極端：

| 情況                                 | 引導方向                                                   |
| ------------------------------------ | ---------------------------------------------------------- |
| 方案過於理想化（如「要求增加空間」） | 引導小組思考：在現有條件下，第一步可以做什麼？             |
| 方案過於籠統（如「要更靈活」）       | 引導小組想清楚：這在日程安排上怎麼做？還是規則上的改變？   |
| 小組對抽到的5張紙條沒有共鳴          | 提醒他們可以從「這個困難背後是什麼」入手，而非只看表面描述 |

若小組紙條過於籠統，可使用**備用挑戰池**（詳見工作手冊）。

### 活動二

**社區集思**階段容易出現的情況：

| 情況                                 | 引導方向                                                                                   |
| ------------------------------------ | ------------------------------------------------------------------------------------------ |
| 小組只列出遊樂場、公園等「標準答案」 | 提示有水、有沙、有斜坡、可自由走動的地方；街市、海濱、古蹟、圖書館等非傳統空間同樣值得考慮 |
| 小組想到的地方很多但缺乏深度         | 引導他們聚焦一個親身去過的地方，把當時孩子的反應說出來——質比量重要                         |
| 小組對某個地點記憶模糊               | 鼓勵從感官入手：那個地方有什麼可以摸？有什麼聲音？孩子在那裏可以自己決定做什麼？           |

**分析注釋**階段容易出現的情況：

| 情況                                       | 引導方向                                                                                         |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| 注釋停留於「設施齊全」、「安全」等表面評價 | 引導轉向遊戲性：這個地方讓孩子主動探索嗎？孩子在這裏可以自己決定怎麼玩嗎？                       |
| 小組難以想像家長的具體角色                 | 幫他們描繪畫面：家長站在哪裏？做什麼？不做什麼？例如「坐在旁邊不發指令，讓孩子決定往哪個方向走」 |
| 推薦的地方對普通家庭不實際                 | 提醒加入現實考量：交通方式、費用、所需時間——一個需要轉三次車的地方，再好也難以推薦               |
| 小組對圖例表的使用感到困惑                 | 建議逐一維度問：「這個地方在『探索性』上如何？孩子可以自己發現新東西嗎？」                       |

**全場分享**階段容易出現的情況：

| 情況                         | 引導方向                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| 代表想全面匯報地圖所有地點   | 輕輕引導：「可以聚焦在一個讓你最印象深刻的地方就好——一個有畫面的例子勝過五個名字」         |
| 分享停留於地點名稱，缺乏畫面 | 追問：「你們在說這個地方時，有沒有一個孩子玩耍的畫面浮現腦海？」                           |
| 各組分享感覺孤立、沒有連結   | 主動串連：點出不同地區的相似元素（如「兩個地區都提到水」），讓發現變成集體洞見            ![1772690478013](image/facilitator_suggested_actions/1772690478013.png) |
| 分享流於概念，欠缺實用性     | 帶出教師角色：今日發現了什麼，就是明天可以告訴家長的東西——不需要等培訓，走出去看看就是行動 |

活動結束後，KeySteps 團隊將把 Padlet 數據整理成可分享的社區資源地圖。帶領員可在總結時讓參加者知道這一點，增加活動的延續感。
